## KRDS 주소 확인 안내

- `https://www.krds.go.kr` 접속을 시도했으나, 현재 클라우드 환경의 프록시가 CONNECT 요청에 403을 반환해 사이트 응답을 확인하지 못했습니다. 사이트 자체의 장애나 주소 오류로 확인된 것은 아닙니다.
- 브라우저에서 주소가 열리는지 확인하고, 열리지 않으면 **“KRDS 디지털정부 UI/UX 가이드라인”**으로 검색해 공식 주소를 확인합니다.
- 이 목록의 다른 사이트는 사용자가 제공한 주소를 저장했으며, 개별 접속 여부는 검증하지 않았습니다.
